# 技术决策记录

> 重大技术决策(选型、数据模型、外部服务)在此记一行:日期、决策、为什么、放弃了什么。

- 2026-11-19 防剧透遮罩(Spoiler Shield):在视频预览上叠加遮挡层,默认遮住整幅画面(含已烧录进画面的字幕),只保留一个可拖拽/缩放的归一化揭示矩形(存 0..1 相对视频坐标)。遮挡效果支持纯色填充、马赛克(块大小可调)、模糊(强度可调)。实现上用固定管线 OpenGL + 每帧 CPU 框平均降采样成小纹理,马赛克用 GL_NEAREST 放大、模糊用 GL_LINEAR 放大,因为该渲染器没有 shader。放弃了"区域打码"(区域外可见)语义而改为"整屏遮挡 + 揭示窗",因为用户诉求是防剧透而非打码;放弃了一开始只做纯色/只做模糊的窄方案以完整覆盖需求。该功能只作用于编辑器预览,导出仍用原始画面。
