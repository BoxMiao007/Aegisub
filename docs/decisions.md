# 技术决策记录

> 重大技术决策(选型、数据模型、外部服务)在此记一行:日期、决策、为什么、放弃了什么。

- 2026-11-19 防剧透遮罩(Spoiler Shield):在视频预览上叠加遮挡层,默认遮住整幅画面(含已烧录进画面的字幕),只保留一个可拖拽/缩放的归一化取景矩形(存 0..1 相对视频坐标)。遮挡效果只保留纯色填充与马赛克(块大小可调)。实现上用固定管线 OpenGL + 每帧 CPU 框平均降采样成小纹理,再用 GL_NEAREST 放大,因为该渲染器没有 shader。放弃了模糊效果:没有 shader 时模糊只能用 GL_LINEAR 放大低分辨率纹理,与马赛克共用同一条降采样路径、视觉上更糊且没有独立能力,维护两套放大分支不划算。放弃了"区域打码"(区域外可见)语义而改为"整屏遮挡 + 取景窗",因为用户诉求是防剧透而非打码。该功能只作用于编辑器预览,导出仍用原始画面。
- 2026-11-19 防剧透遮罩评审修复:旧“草稿图”配置改为在加载用户配置时经 `agi::Options` 的可插拔迁移回调映射到新键(新键优先、旧模糊值归纯色、非法值丢弃),避免升级后设置静默丢失;马赛克纹理按 OpenGL 1.1 的二次幂要求补齐,上传失败时回退纯色,失败也绝不露出画面;无 gettext 的环境改为安装期用 `tools/po2mo.py` 编译全部语言(补上复数/上下文/fuzzy 处理)。放弃在显示层长期保留旧键兼容代码,也放弃只为 zh_CN 手工放 .mo 的临时做法。
- 2026-11-20 遮挡字幕文字与视频防剧透遮罩分开：正文只在显示层按原文排版遮住字形，不在内存稿件中替换字符。因为等宽替代符会挪动标点、改变换行并干扰盲校。
- 2026-11-21 防剧透遮罩整理入口：移除视频右键菜单里的遮罩子菜单，设置统一放到工具栏「遮挡设置」对话框；马赛克块大小改用拉杆，方便边看边调。放弃继续在右键菜单维护第二套设置，因为与工具栏入口重复且容易漂移。
- 2026-11-21 遮挡设置重复应用黑屏：VideoDisplay 的 Subtitle/Text Mask 回调原来每次 Apply 都 InvalidatePreview()，但 AsyncVideoProvider 对相同值不重新发帧，于是确定按钮第二次 Apply 后预览一直黑。改为缓存当前值与替换符，只在值真正变化时失效预览。放弃让 provider 对相同值强制重发，因为会制造无谓渲染。
- 2026-11-21 预览替换兼容 CSRI/VSFilter：用户配置常选 `CSRI/pf-xy-vsfilter_textsub`，原实现只有 libass 提供者支持替换，导致安装版预览仍显示真实台词。现在 CSRI 提供者也按当前替换符重建预览专用字幕实例，导出仍用原实例；同时安装期统一重编译全部 .po，避免便携包沿用旧语言文件导致新字符串显示英文。放弃强制改用户字幕提供者或只修 libass 的单边做法。
- 2026-11-21 实时预览改为替换正文：每个正文文字替换为可配置的替换符（默认 X），标点、空白与 \p 绘图原样保留。因为实心块/隔字方案看不到字宽与行文，替换符能保留行数、位置感，也更便于对轴。替换只在渲染层生成字幕副本，搜索、复制、保存、截图与导出仍是真实台词；因此不再需要逐字形坐标，libass 补丁与 wrap 的 diff_files 已移除，回到原版 0.17.5。放弃在内存稿件里改字，因为那会污染保存与导出。
